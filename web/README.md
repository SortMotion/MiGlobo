# MiGlobo · web

Panel del vendedor y página pública. Next.js 16 (App Router, Cache Components) + Supabase.

```bash
npm install
cp .env.example .env.local
npm run dev
```

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo en http://localhost:3000 |
| `npm run lint` | Revisa el código |
| `npm run build` | Compila como en producción (lo corre CI en cada PR) |
